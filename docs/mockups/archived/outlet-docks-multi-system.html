Plugs live on the tool, in a shop with more than one collector

Every machine is drawn once and carries its smart plug in the row under its name — never on a port, because a plug is one fact about a machine however many ducts reach it. Two collectors, both always drawn: nothing greys out, so anything you can see you can click. Drag a plug onto a machine, or press Match by name and let it assign them.

Smart plugs

What the plug row is saying

no plug — you switch this one on yourself paired, drawing nothing drawing, but under the trip point over the trip point — this machine is running

No amber "is this yours?" state any more. Match by name assigns the plugs it's sure about and the rest get dragged — a per-row suggestion waiting to be accepted was a third thing to learn.

Two ports, and no third

primary — the connection it can't run without secondary — a pickup, drawn hollow

The Table Saw's secondary is on the other collector. That run is dashed and lands on the side of the card, so a machine shared across systems reads as shared rather than as two machines that happen to touch.

Its plug belongs to neither port. Switch the saw on and both want air; which actually gets it is a routing answer, not an electrical one.

Nothing greys out

Both systems are drawn at full strength, always. The dimming this replaces kept producing the same moment: you click a thing you can see, and nothing happens because it belongs to the layer or the system you aren't in.

So there is no focus mode and no ducts/wiring split here. If it's on the canvas, it takes the click.

Each machine's ⋯ menu carries the per-tool actions, including Identify plug — switch the tool on and watch which one jumps.

Exploration · 2026-09-07

Tracing a run from the piece you picked

Pick a machine, a valve or a length of pipe and the canvas follows it back to the collector, so “where does this actually go” is answered by looking rather than by tracing a grey line with a finger. Click anything below. Not the shipping canvas — this page exists to settle the treatment before any of it is built.

Try it

Nothing picked. Click a machine, a valve, or a run.

What this page is asking you to decide

1 · A halo, in the line's own colour. Recommended

All three treatments are in the toolbar. The halo is not a new mark at all: it is exactly what a selected box already gets — a ring and a soft outer bloom — applied to a line and kept in that line's own colour. Grey pipe stays grey pipe with a rim of light around it; the cable's rim is azure. Nothing is recoloured, so nothing has to be learned (jeff, 2026-09-07: "try this same effect, but in the existing colour of the line").

This page originally argued for brightening instead, because a glow was already spoken for: D-66 puts a soft orange bloom on anything with a problem, and a second bloom differing only in hue is a mark you have to look twice at. Keeping the halo in the line's own colour dissolves that objection. Hue is precisely what separates the two — orange means "something is wrong here"; grey-on-grey and azure-on-azure mean "this is the path you asked about". A traced run passing straight through a piece that carries a problem halo still reads correctly, which is the case that killed the white glow. Pick the Drum Sander with each in turn.

Brightening stays in the toolbar as the fallback. It is honest and cheap, but it changes the pipe's colour in order to say something about selection; the halo says the same thing without touching the pipe.

2 · Dim the rest, gently. Recommended

Lighting one path in a shop of twenty runs is not much use if the other nineteen are equally loud. Focus dims rather than hides (mockup rules), so everything else drops to about a third and stays perfectly readable — you can still see what you are about to pick next.

3 · Upstream always; downstream to the first branch. Recommended

Upstream is never ambiguous: every port has exactly one parent, so “back to the collector” is a single chain. Downstream forks, and at a fork we genuinely do not know which leg you meant — so it stops there, and says it stops, with a small bar across the pipe at the branch. A highlight that just petered out would read as a rendering artefact; a deliberate stop reads as “this is as far as one answer goes”.

Worth trying both ways: pick the Cyclone with “continue downstream” on and the trace stops almost immediately, at the first tee. That is honest, and it is also a good argument that downstream is the less valuable half.

4 · The cable comes too. Recommended

One pick answering both “where does this air go” and “what drives this” costs nothing extra to read, because cable already looks nothing like duct — azure, thin, a different shape of line. It is the same brightening rule applied to a line whose colour is already distinct, so the two lit paths never blur into one.

The cables drawn above are placed by hand, not solved by the wiring layer — this page is about the treatment, not the geometry.

5 · What triggers it. Open

Selection, certainly — tapping a piece is already how you focus it, and this is just what focus now shows. The open half is hover: on a desktop, hovering could preview the same trace without changing the selection, which is what the existing TODO item asks for. Hover is never the only trigger (mockup rules), and here it would be a preview of something selection does properly, so it stays legal. It needs a story for touch, where there is no hover: probably none, and the tap is enough.

6 · Not proposed: flow direction. Open

Arrows, or a crawl along the lit path, would say which way the air moves. Deliberately left out: the trace already runs to a collector at one end, the vocabulary is crowded, and an animation on a canvas you are dragging pieces around is a distraction with a battery cost. Easy to add later; hard to take back.

Where this came from

The standing TODO item asks for ducts and wires to be highlighted on hover, so a run can be traced start to end, and suggests a glow. This page is the same need approached from selection instead — jeff, 2026-09-07: “once a tool or valve or duct is selected, follow its line back to the dust collector and highlight everything in the route… optionally continue away from the collector until it hits a branch.”

A second pickup on the same machine

A table saw collects from two places — the cabinet under the blade and the overarm guard — and they are two ducts behind two gates. The model has carried that since the shop container: a machine owns exactly one primary port and up to two supplemental ones, each a proper one-parent leaf in whichever system it hangs off (shop.js). The canvas has never offered a way to make one.

The thing to get right: a second port is not a second machine. One plug, one trip point, one name, one thing you switch on. Whatever the canvas draws has to say the same saw, again — because a drawing that reads as two saws is a drawing that says this shop has more machines than it has.

Adding one

On the tool's own tap menu, under its plug — the menu that already answers "what is this piece". The new port arrives as an open end you drag out and put a gate on, exactly like any other run, so nothing new has to be learned to plumb it.

The primary port is never offered for deletion — it is the connection the machine cannot run without, so the only way it goes away is with the machine. A supplemental one deletes like anything else.

…and it lands as an open end

Until it's plumbed it is an unfinished thing, and the guide bar says so the way it does for any open end. Once it's behind a gate the body goes solid.

What a second port looks like

Each panel shows the same shop: the saw's cabinet port on the main gate, its overarm pickup behind a gate on the second collector.

A · One machine, two spigots

the pick
One box, so one machine

No second body at all — the saw keeps its one box, its one name and its one plug, and grows a second inlet of a different shape. A square spigot is the machine's main port; a tapered hood is a pickup, which is what an overarm guard physically is. The role is captioned beside it, and the run below it goes where it goes.

B · A second, shorter body

Says the machine twice

The port gets its own shorter body with the role where the plug row would be, and a dashed link home. It reads correctly once you've noticed the link — but the name is on the canvas twice, and a scan that misses the dashes counts an extra machine. It is also the only option that puts a machine's name inside a system it doesn't belong to.

C · A full tool with a badge

Says the wrong thing

Identical body, same plug row, a small "2" to tell them apart. At the 55% a phone uses you can't read the badge, and what's left is a shop with two table saws in it — each apparently with its own plug. Drawn to be rejected.

What A costs, since it isn't free

A duct now crosses the seam. I said earlier that air never does — that was too strong, and A is where it shows. What is structurally true in shop.js is narrower: no duct is shared between two systems and no element belongs to two of them, so the two trees stay separate. With the machine drawn once, the second system's run has to leave its own band to reach the box — which is honest, because the saw really is connected to both collectors. The seam still divides the trees; it just stops being a wall.

The port stops having a cell. Every other element owns a grid cell, and the layout, the drop checks and the band rule are all written in cells. A pickup drawn as a spigot on someone else's box has no cell of its own — it is an anchor on the machine's box, and the router terminates at it. That is the real implementation cost of A, and it is confined to one place: where a duct's endpoint is resolved.

The run stays solid. It is real ductwork, not a relationship — the dashed line in B is a claim about identity, which A doesn't need to make because there is only one box. Dashes are also spoken for: an unfinished run already wears them.

Decided against, 2026-08-19. Tools only ever exist in one system — a machine's ports don't split across two collectors. Everything below this line was the ambitious half of this mockup and isn't happening. Section 2 above (Option A, same-system pickups) still stands.

When the pickup is on the other collector

This is the case the shop schema exists for: the cabinet port on the cyclone, the overarm on the shop vac. The dashed link is then the only thing that crosses the seam between two systems — air never does.

The plug stays on the primary, in the system the machine calls home. Switch the saw on and both gates open, on both collectors — which is the whole reason the shop schema lifts machines above the airflow graphs instead of letting a tool have two parents.

Outlet docks

The tool body grew a second row and the outlet lives in it — one object on the canvas, machine and plug together, where the auto / manual caption used to sit. Point at one (or tap, on a phone) to read it; whatever is running stays open on its own. Drag a plug out of the tray onto a tool, or let the names match themselves.

Reveal, not hover

Hover alone would strand every phone, so the detail is bound to a revealed state instead. A mouse reveals by pointing; a finger reveals by tapping; and a running tool reveals itself and stays open.

That also fixes accepting a name match by accident: the first tap opens the row so you can read which plug it means, and only the tick commits it. The unanswered question wears a static amber dot — nothing on this canvas blinks.

Trip point defaults to 100 W for every tool, adjustable per outlet. Real numbers to follow from the shop.

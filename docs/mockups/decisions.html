Decision register

Every decision that still stands, with the reason and where it lives. Reversed and superseded calls are not here — only the version in force, so this can be read as fact rather than history.

Adding one: append an object to DECISIONS at the top of this file. Newest first. If a decision replaces an older one, edit the old entry rather than adding a second — two entries that disagree is the failure this register exists to prevent.

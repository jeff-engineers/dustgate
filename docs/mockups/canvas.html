The shop canvas

The single source of truth for how the build canvas looks and behaves. Every other mockup in this folder has been archived — their reasoning is still worth reading, but a decision that matters lives here.

How to use this page. Update it in place. When a decision is made, change the section it affects here and add an entry to the decision register. Do not open a new mockup for a settled question — that is what produced seven pages that disagreed with each other.

1 · The marks and what they mean

Every line style on the canvas, in one place. This list exists because "dashed" was read as meaning two different things at once; it means exactly one thing per colour.

Duct
Real ductwork inside one system. Solid, grey, full weight.
Secondary run
A supplemental port's run — and the only thing allowed to cross the seam between two systems. Grey, dashed, thinner.
Open end
Pipe with nothing on it yet. Accent orange, dashed — never grey, which is what keeps it distinct from a secondary run.
Cable
A board's wire to a gate. Azure, thin — never the app's red, which already means danger.
Cable, mid-drag
Only while you are dragging one. Azure keeps it unambiguous against the orange open end.
Spigot — square
A machine's primary inlet. Drawn only when the machine also has a pickup; its duct lands on it.
Hood — tapered
A pickup: an overarm guard, a hood. What one physically is. Its role is captioned beside it.
Spare inlet
Room for another pickup. Hollow and dashed like an unwired tab — drag out of it to run a pickup's pipe.
Ground & seam
One grey band per airflow system. Only drawn once there are two — with one collector it would say nothing.

2 · A machine is one box, however many ports it has

Built

Two inlets, one body

A second pickup is a differently-shaped inlet on the same box — never a second body, never a dashed identity link. A drawing that reads as two saws is a drawing that lies about the shop.

Where a machine lives

A tool belongs to exactly one system and is drawn there, once. A secondary port's run may be fed from the other collector — that is the one thing permitted to cross the seam, and it is drawn as a secondary run so a shared machine reads as shared.

The rule, stated once. A machine lives in one system. A machine's ports are elements in the airflow tree, each with exactly one parent duct — a tool may never have two parents, which is why a second pickup is a new port element rather than a second parent on the old one. A supplemental port's run is the only run allowed to cross the seam, and may be disconnected and re-routed to a primary on the second system if that is what the shop wants.

3 · What can stop a drag

Built · 2026-08-20

Almost nothing. A user is never blocked from moving a piece because the shop is in a bad state — a broken layout is exactly the thing they are dragging their way out of. Only two things refuse a drop:

ConditionResult
The cell is occupied Refused. Named: "Bandsaw is already in that cell."
The row belongs to another system Refused. Systems own contiguous row bands; interleaving them makes the grey ground undrawable.
A duct will cross a device Allowed. Advisory only — says what the drawing will do.
A duct loses its clear way in Allowed. Advisory, and baselined so it reports what this move breaks.
A duct runs through a board's new cell Allowed. Ducts route around boards, so the run simply moves.
The shop is leaking / unfinished / invalid Allowed. Never a reason to freeze the canvas.

Advisory text is written in the present tense ("The duct will have to run through Table saw") and rendered muted, not amber — an alarm colour on a move that is about to succeed reads as "stop".

4 · Adding a second pickup

Built · 2026-08-20

One gesture, either direction. The two ends of a pickup's run are a machine's spare inlet and a gate in the other system — and you may start the drag from whichever of them you happen to be looking at.

Pull it in

gate → machine

Drag any loose end onto a machine that already has a duct — a run's open end, or a free outlet stub straight off a manifold, collector or sliding gate. The machine highlights, because already having a duct is what makes this a second port rather than an ordinary connection.

Or pull it out

machine → gate

Every machine with room for another pickup wears a hollow inlet. Pull a run out of it and drop it on a gate, a free outlet or a loose end — including one across the seam, which is the case this whole treatment exists for.

Either way, it asks

The same sheet, the same port, whichever direction you dragged. Two outcomes, because there are only two: it is a second pickup, or it was a misdrop.

The name is the user's. It arrives as Auxiliary and is editable right there — only the person with the shop knows whether that hose is an overarm guard, a downdraft table or the second port on a lathe, and the name is what gets captioned beside the hood.

It needs no schema change. The supplemental port element lives in the system that FEEDS it, alongside the gate it hangs off — only the box it is drawn on sits in the other band, so nothing structural crosses the seam and validateShop is untouched. Both test suites already carry the shape: a table saw with its cabinet port in one system and its overarm in the other.

Why both directions. The two ends live in different systems, often far apart on a stacked canvas. Forcing the drag to start at the machine means scrolling to it after you have already found the gate — and forcing it to start at the gate means the reverse. Neither end is privileged, so neither is made the only handle.

What it replaces. The tool-menu route creates an unattached open end, picks its cell with no collision check, and leaves the document invalid until you plumb it. Measured on the demo shop, that end lands at (496,172) — Main gate's outlet 4, already feeding the manifold. The menu item goes away; two ways in would mean keeping the broken one.

5 · Decisions

Every decision — canvas and otherwise — lives in docs/mockups/decisions.html, the register. It is searchable and filterable by area, and records the open questions too. This page does not keep its own log: two lists that drift apart is the exact failure that produced seven disagreeing mockups.

Where the old pages went

All of them are in docs/mockups/archived/ with a banner saying what replaced them. They are worth reading for why — the alternatives that were drawn and rejected are not repeated here — but nothing in that folder is current, and nothing there should be treated as a decision.

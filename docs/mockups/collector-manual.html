A switch for the dust collector

The collector card has no control. Starting a blower from the app means switching a tool on, and there is nothing to press when you only want suction, to clear a clog or to run the collector with no tool. This draws one back in the same style as the tool rows: tap the card.

Why it is not simply the old switch. A switch on the card was removed on 2026-10-03 because the blower and the tools each had their own idea of what "off" meant: run a tool, tap the switch off, and the tool kept asking for the blower. Two things have changed since, and this design leans on both: a blower started by hand now stays on until someone stops it (the brain never presses OFF for a run it did not start), and using another tool ends a hand-switched one in the same system. So a hand run has one owner, the person, and a clear end.

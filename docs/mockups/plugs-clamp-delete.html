The clamp switch, deleting a system, and a Plugs page

Three screens, all clickable. Everything shown is example data. The Boards row follows /boards; the canvas menu is the existing ⋯ menu with one new item; the Plugs page is laid out like /boards so the two read as siblings.

Boards · a current clamp is something you switch on

Today every node says it has a clamp, fitted or not. Now a node starts with no clamp, and you turn one on for the board it is plugged into. The setting is kept in the layout on the brain, so reflashing a node does not lose it.

Canvas · delete a second collector, or clear the shop

A collector after the first can be deleted, and its whole system goes with it. The first collector has no delete (a shop needs one). Clear shop sits at the bottom of the ⋯ menu and does the same to everything except the first collector.

What I chose that you may want different

  • The clamp setting lives in the layout, on the board's entry, not in the node. A reflash cannot lose it, and the brain stops trusting “I have a clamp” from the node alone.
  • Turning a clamp off asks first only when a tool is sensed by it. Otherwise the switch just flips.
  • Deleting a collector deletes its whole system. A machine with a port on another system keeps that port; one with no other port goes.
  • Clear shop keeps boards and pairings, so you do not re-pair six boards. It releases plugs paired to removed tools. Tell me if you would rather it leave plugs alone.
  • Plugs is a page in its own right, reachable from the ⋯ menu where “Find plugs” is now. The Build canvas tray stays for placing a plug, and the picker in tool setup is replaced by “Pair to…” here.

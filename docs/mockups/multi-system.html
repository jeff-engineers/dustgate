DustGate · build canvas

A second collector on the same canvas

The model has carried N airflow systems for a while — the container, the per-system checks, the live view's "3 dust collectors". The build canvas is the last thing that only knows about one: it picks systems[0] at load and never offers another. This is what adding the second one could look like.

The load-bearing fact: a system is exactly one collector and one duct tree, and no duct is ever shared between two of them — that's structural in shop.js, not a convention. Air never crosses from one system to the other. Only a machine does, when its overarm pickup hangs off a different collector than its cabinet port. So the line between systems never has to be searched for; it only has to be drawn.

Adding one

A shop grows a second collector roughly once, so this belongs in the overflow next to Import and Export rather than on the toolbar. The new collector lands below everything already drawn, with its own trunk lane — the same left-rail band the first system got.

⋯ menu

Naming can wait for the plug: the collector's name is already whatever its smart outlet is called, so a second one arrives as “Shop vac” without a dialog.

The band rule

why the line is free

Each system owns a contiguous range of rows, and a drag that would land in the next system's rows grows its own band instead of crossing. That single invariant is what makes the divider one horizontal line at a known row — no search, no A* run per repaint, and no case where the answer is "there isn't one".

Drawing the boundary

Three treatments of the same two-system shop. The dashed amber line in each is the table saw's overarm pickup, which hangs off the shop vac while its cabinet port stays on the cyclone. It is not a duct — it is the machine, saying "these two boxes are one tool".

A · Rule + name chip

the pick
Reads at 60% zoom

A hairline the full width of the board, with the second system's name in a chip on the left where the trunk starts. Costs two rows of canvas and survives being scaled down, which the tint below doesn't.

B · Tinted bands

Quiet, but fragile

No line at all — the first system sits on a 2% lighter ground. It is the calmest of the three and it disappears on a phone in daylight, which is the screen this is for. It also collides with the live-highlight wash.

C · Gutter + label

Clearest, most expensive

A real gutter with a header strip — unmistakable, and a place to hang a per-system summary. It eats a full band of canvas on the one axis a stacked layout is now spending, and it turns the drawing into two documents rather than one shop.

Recommendation: A. The rule survives the zoom-out that B doesn't, and doesn't spend the vertical room that C does. If a system needs a summary later it can go in the chip, which is already a place for text.

All three share the same two rules underneath: bands never interleave, and a dashed amber link means one machine on two collectors, never airflow. Those are the parts worth agreeing on — the line style is the easy bit to change afterwards.

Telling a tool from a gate

Today a tool and a gate are both a dark rounded rectangle with a pale label, differing mainly in proportion — which is the first thing lost when the drawing scales to fit a phone. Three ways to separate them, ordered by how much they change.

Today

shape only

The plug chip is already a tool-only marker, but it's the smallest thing on the piece and it's the first casualty of zooming out.

A · Ductwork is steel

the pick
Survives the zoom-out

Two changes, both cheap: gates and valves take the cool steel of the ducting and go a shade darker than the board; machines go a shade lighter, warm. Gate names drop to small muted caps so they stop competing with tool names. Value contrast is the last thing to survive scaling — this still reads at 40%.

B · Give tools a hood

Truthful, but busy

A + a small hood wedge where the duct meets the tool. It says the real thing — the run stops here — and it gives the box an asymmetric silhouette you can pick out at any size. It also adds a fourth shape to a drawing that is already carrying five, and it fights the setup badge for that corner.

What this doesn't touch

Nothing here changes the topology, the router, or what saves to the device. The system divider is a rendering rule over a band invariant; the tool/gate separation is fill, stroke and label weight. Both are reversible in an afternoon if they don't survive contact with a real shop.

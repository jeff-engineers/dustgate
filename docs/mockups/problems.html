What the brain reports

One list, problems, in /api/status. Each entry says what, why, since when, and which part of the shop. The UI draws it and invents nothing — the device words the reason.

codewhen it appearsclears when

Rules

1. Never dismissible — it goes away when the cause does; hiding it is how it gets forgotten.

2. Red = something you asked for isn’t happening. Amber = it’s degraded but working.

3. A tap that fails says so at the tap (toast), with the device’s reason — and the same fault then stays in the list.

4. If the app can’t reach the brain at all, that is the first and only problem shown, and everything below greys out.

5. Each entry links to the Brain log (opens on the Problems chip) and, where there is one, to the fix.

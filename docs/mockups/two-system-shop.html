One machine, one glyph

A machine belongs to the shop, not to a system — so it's drawn once, with a port tab where each duct lands. The saw has a 4" tab on top and a 2.5" tab on its right, and the auxiliary hose is drawn crossing the room because that hose exists.

The ducts still never cross systems: the overarm's duct runs from the manifold to the saw and both ends live in the 2.5" system. Only the machine spans them.

What focus lights up

Plumbing dims with its system. A machine stays lit if any of its ports is in the focused system — so the saw is bright in both, never cut in half.

A machine with an unassigned port stays lit in every focus. The bandsaw's upper-guide pickup isn't plumbed yet, so it never hides — unfinished work is the last thing that should disappear when you narrow the view.

Try it

Click a machine to run it. Click a port tab to take that port out of service — the overarm starts that way, hood off for a non-through cut.

The contention case: put the overarm back, run the table saw, then start the bandsaw. The overarm gives way and says who took it; the 4" cabinet port is untouched. Start them in the other order — same result. Primary beats supplemental, recency never overrules need.
